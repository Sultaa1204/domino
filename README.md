# معلّم الضومنة — أونلاين

لعبة ضومنة تلعبها مع أخويائك، كل واحد من جهازه. فيها:

- غرف بأرقام: تسوي غرفة وترسل رقمها لأخويائك.
- لعب أربعة (فريقين) أو لاعبين.
- المقاعد الفاضية يلعب فيها بوت ذكي.
- مدرّب يحلل حركاتك، ومستوى ينحفظ على جهازك.

السيرفر هو اللي يوزّع الأحجار، فكل لاعب ما يوصله إلا أحجاره.

ما يحتاج أي مكتبات. يكفي Node.js نسخة 18 أو أحدث.

## الملفات

| الملف | وش فيه |
|---|---|
| `server.js` | السيرفر: الغرف، توزيع الأحجار، البوتات، البث المباشر |
| `engine.js` | محرك اللعب والتحليل (نفس اللي في الصفحة) |
| `public/online.html` | صفحة اللعب أونلاين |
| `public/index.html` | صفحة اللعب لحالك ضد الكمبيوتر |

## تشغيله على جهازك (للتجربة)

1. نزّل Node.js من nodejs.org.
2. افتح الطرفية (Terminal) داخل المجلد، واكتب:

   ```
   npm start
   ```

3. افتح في المتصفح: `http://localhost:3000/online.html`

إذا أخويائك معك على نفس شبكة الواي فاي، يقدرون يدخلون من جوالاتهم على `http://عنوان-جهازك:3000/online.html`. عنوان جهازك تلقاه في إعدادات الشبكة، ويكون مثل 192.168.1.20.

## رفعه على الإنترنت مجاناً (Render)

عشان أخويائك يدخلون من أي مكان:

1. سوّ حساب في github.com، وسوّ مستودع جديد (New repository).
2. في صفحة المستودع اختر "uploading an existing file"، واسحب كل الملفات والمجلدات، وبعدها اضغط Commit.
3. سوّ حساب في render.com، واربطه بحساب GitHub.
4. اختر **New** ثم **Web Service**، واختر المستودع.
5. عبّ الإعدادات كذا:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
6. اضغط **Deploy**. بعد دقايق يعطيك رابط مثل `https://domino-xxxx.onrender.com`.
7. رابط اللعب أونلاين يكون `https://domino-xxxx.onrender.com/online.html`.

**ملاحظات على الخطة المجانية** (حسب شروط Render، وممكن تتغير):

- السيرفر ينام إذا ما استخدمه أحد فترة. أول فتحة بعدها تاخذ تقريباً دقيقة.
- لما السيرفر ينام أو يعيد التشغيل، الغرف المفتوحة تنمسح، وتحتاجون تسوون غرفة جديدة.

## طريقة اللعب

1. افتح `online.html`، اكتب اسمك، واضغط "غرفة أربعة" أو "غرفة لاعبين".
2. أرسل رقم الغرفة أو "رابط الدعوة" لأخويائك.
3. كل واحد يدخل الرقم، ويضغط على المقعد اللي يبغاه. في لعب الأربعة، المقعد اللي قدامك هو خويّك.
4. المضيف يضغط "ابدأ اللعب"، والمقاعد الفاضية يلعب فيها بوت.
5. تحط الحجر بسحبه للباب اللي تبغاه، أو تضغطه وبعدها تضغط الباب.
6. إذا فصل أحد، اللعب يكمل. وإذا جاه دوره وهو مفصول، يلعب عنه بوت بعد 25 ثانية. ولما يفتح الرابط مرة ثانية يرجع لمكانه.
7. بعد كل جولة، أي لاعب يضغط "الجولة التالية".

## إعدادات اختيارية (متغيرات البيئة)

| المتغير | الافتراضي | وش يسوي |
|---|---|---|
| `PORT` | 3000 | منفذ السيرفر (Render يحدده بنفسه) |
| `BOT_THINK_MS` | 350 | وقت تفكير البوت بالملي ثانية (أكثر = أقوى) |
| `AWAY_BOT_MS` | 25000 | بعد كم يلعب البوت عن اللاعب المفصول |
